### 奔腾服务队招新｜修电脑、教手机、攒时长，一起做点有用的事

你好，我们是**奔腾服务队**。

一个为学生和社区提供**电脑义诊服务**的志愿者组织。我们在校内和社区，帮大家解决电脑和手机上的小麻烦。

**我们主要做什么？**

- **校内电脑义诊**：每月一次，周末 **10:00-17:00**，单次最高可认证 **8小时志愿时长**。
- **电脑维护服务**：笔记本电脑清灰、换硅脂、清理C盘、重装系统等。
- **社区志愿服务**：帮助社区里的老年人解决手机使用问题，比如微信、支付、清理存储空间等日常操作。

**加入奔腾，你能获得什么？**

1. **志愿时长更省心**  
   不用在年级群里拼手速抢志愿活动。队内每月固定开展义诊，周末出摊，单次最高8小时志愿时长，轻松积累志愿经历。

2. **学到真正实用的电脑技能**  
   了解计算机软硬件知识，学会笔记本清灰、换硅脂、C盘清理、系统重装等。能更好地保养自己的笔记本电脑，在这波硬件涨价潮里，让老电脑再战几年，少花冤枉钱。

3. **一个松弛但互助的团队氛围**  
   我们组织看起来比较松散，但这正是我们的优势：不高压、不内卷，很多队员同时兼任其他社团，也有英语、专业课很强的同学，乐于在学业上互相帮助。你可以在这里认识一群靠谱、友好、愿意分享的伙伴。

**我们希望你：**

- 对电脑软硬件、志愿服务或社区服务感兴趣；
- 有耐心，愿意和同学、老年人沟通；
- 愿意动手、乐于协作，一起把义诊活动做好；
- 不要求一开始就是技术大佬，愿意学、愿意参与最重要。

加入招新 QQ 群：817913439

**培训方式**：

周末一次*约2h*的线下硬件和软件知识培训。具体时间地点待招新群内通知。

## 网页说明（给上游 owner）

纯静态单页，**免构建**，双击 `Pentium/index.html` 或部署后访问 `Pentium/` 即可。

### 目录结构

```
Pentium/
├── index.html      # 整页结构（Hero / 我们做什么 / 在这里收获 / 新手指南 / FAQ / 加入我们）
├── styles.css      # 样式与响应式布局（约 20 KB）
├── script.js       # 交互：抽象版文案切换、C 盘清理小演示、入群弹窗与复制群号
├── images/
│   ├── dragon-logo.svg   # 龙标（页眉 / 页脚 / 加入我们区块）
│   └── psc.webp          # 招新圆形徽章（600×600，38 KB）
└── 抽象版.txt      # 「抽象版文案」的原始文本，供改文案时对照
```

### 资源说明

| 资源 | 是否需要打包 | 说明 |
| --- | --- | --- |
| `images/dragon-logo.svg` | 需要，已入库 | 矢量图，任意尺寸都清晰 |
| `images/psc.webp` | 需要，已入库 | 页脚 / 徽章位使用 |
| `抽象版.txt` | 不需要 | 纯文本备注，不会被网页加载 |

### 离线与部署

- 无 CDN、无在线字体、无外链图片，字体使用系统栈（`SFMono-Regular / Consolas` 等）。
- 站内引用全部是相对路径（`styles.css`、`script.js`、`images/...`），放在任意子目录下部署都能正常工作。
- 入群群号写死在 `index.html` 中（当前为 `817913439`），如更换请全文替换（页脚、加入我们、弹窗共 3 处）。
